What is an agent

An instance that the host actually created and that produced work.

What is not an agent

An engineer.md file, a skill, or a role label. Those are templates.

Final responsibility

The orchestrator launches the architect and its assignments, verifies evidence, and integrates approved delivery. It cannot perform task work alone or invent nodes.
